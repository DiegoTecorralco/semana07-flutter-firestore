# Catálogo reactivo — Semana 07

Proyecto de práctica Flutter + Cloud Firestore con CRUD en tiempo real, estados de carga/error/vacío, caché y arquitectura Modelo–Repositorio–Vista.

**Empieza leyendo `docs/GUIA_PASO_A_PASO.md`.**

El proyecto necesita ejecutar `flutter create --project-name semana07_firestore --platforms android,ios,web .` para generar las carpetas nativas y `flutterfire configure` para generar `lib/firebase_options.dart`. Esas credenciales no se incluyen.
